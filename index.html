WhatsApp CRM + M-Pesa

Chat-commerce payments platform

  • Receives WhatsApp messages via HMAC-verified webhooks, replies with an automated bot and takes M-Pesa payments.
  • Callback handling with status polling as a fallback, written so a repeated callback is never recorded twice.
  • PDF receipts sent on WhatsApp, plus a React dashboard with JWT login and role-based access.

2025 Logistics

Boda Dispatch

WhatsApp delivery CRM

  • Dispatch system that runs directly inside WhatsApp using the WhatsApp Cloud API.
  • Migrated SQLite → PostgreSQL, using transactions and row-level locking so two riders can't claim the same delivery.
  • Round-robin algorithm to share deliveries between riders, with separate access for dispatchers and riders.
